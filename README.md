# RuralNative-SKILLS

Use this skill when you need to set up, audit, or maintain agent-facing architecture documentation so AI agents navigate and modify your codebase accurately.

## Skills

### doc-architecture

The doc-cache lifecycle for a codebase: establish, audit, or maintain architecture documentation — an index, ADRs, glossary, and a change-aware harness — so docs stay coherent with code. Documentation is treated as a cache: it stores what re-deriving from code would cost, and the skill runs the coherence protocol against it.

**Install:**

```bash
npx skills add RuralNative/RuralNative-SKILLS --skill doc-architecture
```

For manual installation, see the skill's `INSTALL.md`.
