# Faster review-this plan

Authoritative work plan: https://github.com/RuralNative/RuralNative-SKILLS/issues/170

The implementation preserves INV-1 through INV-13 and all current review gates. It will:

1. Dispatch up to three ready PR workers concurrently without exceeding the four-worker workspace cap.
2. Run cloud collection and local review concurrently for each pinned revision pair.
3. Build one shared revision packet for the fresh Standards and Spec agents.
4. Record critical-path timings and benchmark the old and new skill on clean-wave and one-fix scenarios.
5. Update `SKILL.md`, host-neutral helpers, tests, `REVIEW.md`, the seam leaf, and install smoke guidance together.
6. Pass targeted tests, `npm run verify`, and `./scripts/docs-check.sh` without reducing the fix-round budget or skipping final whole-spec review.
