# 0003 — Human-first docs are derived artifacts

Status: accepted
Date: 2026-08-18

Decision: Human-facing documentation lives under `docs/human/`, derives
exclusively from authored docs (ADRs, glossary, seam table, leaf docs, debt
register — never code parsing), carries `Derived:`/`Sources:` headers, and is
regenerated by agents in the same diff as source changes. Agents regenerate
human docs but never cite them as technical ground truth; agent read sets and
loading protocols exclude the human tree, and links point one way (human →
AI).

Why: the proposal's strict decoupling banned the only scalable maintenance
workforce while plain-language restatements are the fastest-decaying docs.
Derivation bounds their decay by slow sources and makes freshness mechanical;
read-set absence is the only mechanical AI-prevention that works (agents
navigate by the index).

Consequences: the gate gains a human-docs extension (read-set absence, link
direction, derived freshness), dormant until the first human doc; the decision
journal becomes the stakeholder intervention surface; the API-reference
artifact is replaced by a dormant capabilities catalog.
